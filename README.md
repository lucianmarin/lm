# LM

Personal website of Lucian Marin, a Python developer and designer. It lists web apps, open source projects, contact details, a short resume and social links.

The site comes in two versions with the same content, in `basic/` and `advanced/`.

### Basic site

- human code
- simple to edit
- no AI agent changes
- single scrolling page of colored blocks


### Advanced site

- human friendly code
- as simple as possible to edit
- AI driven accordion layout
- vanilla JavaScript, no libraries
- vertical panels with 90 degree rotated section labels at the top
- desktop: as many panels open as the horizontal space allows (opened in order on start)
- mobile (639px and below): horizontal accordion, full-width labels stacked, one panel at a time
- panels open and close with CSS animation
